# Head candidate v010: bounded likeness pass (lower face, fringe, eyes)

Status: review candidate for Codex's native matched-camera check (brief at `7234913`). Reversible: v009 stays
archived (`head_candidate_v009.glb`, sha `255f781e...`). The friendly expression is kept. Not a parity claim, no A1
approval.

## Normalised first, then changed

`renders_v010/head_v010_reference_comparison_normalised.png` scales and moves each model render so its eye centres
land on the reference's eye centres. Those were found in the approved reference crop as the two dark blobs, at
(311, 340) and (411, 320) in the 672 px crop. Measured that way, at the reference camera:

| | Eye-to-chin depth / eye spacing | Lower-face width, front half, Z 1.05 m | Same at Z 1.06 | Cheeks, Z 1.10 |
|---|---|---|---|---|
| Reference | about 1.13 (1.08 to 1.18; chin read by eye from the blurred crop, +-5 px) | | | |
| v009 | 1.131 | 202.7 mm | 230.9 mm | 273.9 mm |
| v010 | 1.091 | 222.5 mm | 240.4 mm | 274.1 mm |

What this showed, and corrected in my own first attempt: v009's lower face was not too LONG for the reference. Its
depth already matched. It was too NARROW and ended in a point. A first v010 build lifted the chin 9 mm (ratio 1.054,
shorter than the reference) and was backed off before delivery. My earlier eyeballed "reference about 1.05" used a
wrong eye spacing; the detected one replaces it.

## Honest issue list

1. **A likeness gap this pass did not touch.** Eye-normalised, the model's whole head and hair read larger than the
   reference's. Put the other way, the eyes sit closer together for the head's size. Fixing it means spacing the eyes
   or changing head scale, which this brief ruled out from the full-body panels. Flagged for Codex's native
   matched-camera judgement.
2. The hair is still the broad sculpted plate arrangement Codex named. Only four fringe locks changed.
3. Brows still show between the fringe tips in the front view; the reference hides more of them.
4. Reference chin height is read by eye from a blurred crop (+-5 px), so the ratio is a range, not a target.
5. Not run in Godot. Blender light differs.

## Proposed next action

Codex checks v010 natively at the matched cameras against v009 and the reference. If the lower face and fringe hold,
the next head decision is item 1 (eye spacing against head size), which needs Codex's or the user's go-ahead because
it touches the whole-head proportion.
